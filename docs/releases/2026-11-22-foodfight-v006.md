# FoodFight v0.0.6 release record

**Release date:** pending  
**Status:** In development  
**Scope:** Runtime hardening and release verification  
**Specification:** [2026-11-22-foodfight-v006-runtime-hardening.md](../specs/2026-11-22-foodfight-v006-runtime-hardening.md)

## Objective

Prevent the Android Worklets closure regression found in the first v0.0.5 APK from returning in later releases. The release adds both source-level and compiled-bundle checks without changing the UI-thread gameplay architecture.

## Planned deliverables

- Worklet source regression test.
- Hermes Android bundle verifier after `expo export`.
- Version metadata and changelog for v0.0.6.
- CI-verified PR and EAS preview APK.

## Validation gate

Automated validation must pass before the PR is opened: 140+ Vitest tests, typecheck, lint, Expo Doctor, Android export, and `npm run verify:android-bundle`. Physical Android smoke testing remains the final user/device gate.
