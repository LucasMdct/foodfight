## Scope

v0.0.5 is the stabilization release for the v0.0.4 gameplay baseline. It adds persistent best-score storage, safe background/resume behavior, transition-accurate collision, design-verified hero bob offsets, and the Android runtime upgrades required by the release build.

## Runtime hardening

- Expo SDK `57.0.33`, React Native `0.86.3`, Reanimated `4.5.1`, and Worklets `0.10.1` are used for the Hermes-fixed runtime.
- React Native Skia is pinned to `2.14.0` through the documented Expo install override.
- Worklet helpers resolve `GAME_CONSTANTS` inside the worklet body instead of in default parameter initializers. This prevents the Android `ReferenceError: Property 'GAME_CONSTANTS' doesn't exist` crash observed in the first v0.0.5 APK.

## Device gate

Physical Android smoke testing remains required for final gameplay sign-off. The critical path is: install the release APK, choose each hero, enter the Barão match, use `PODER!`, background/resume the app, and complete both defeat and victory sequences. Capture `adb logcat` if any native crash remains.
